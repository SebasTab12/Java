1. DESCRIPCIÓN DEL PROYECTO
================================================================================

Es una API REST hecha en Java con Spring Boot, sin base de datos. Los datos
están escritos directamente en el código (en memoria, dentro del controlador),
igual que en el video de referencia.

La API permite:

    1. Comprobar que el servidor está funcionando.
    2. Obtener la lista completa de ejercicios.
    3. Filtrar los ejercicios que trabajan un músculo específico.

Tema elegido: ejercicios de entrenamiento y los músculos que trabajan.

Cada ejercicio tiene esta información:

    - nombre
    - músculos que trabaja (lista)
    - equipo o material necesario (lista)
    - series y repeticiones recomendadas
    - beneficios (lista)
    - precauciones (lista)
    - errores comunes (lista)
    - recomendaciones (lista)

Son 10 ejercicios cargados manualmente en una lista inmutable (List.of).

el tema de medicamentos por ejercicios y músculos.

package com.example.ejercicios;

import java.util.List;

public class Ejercicio {

    private String nombre;
    private List<String> musculos;
    private List<String> equipo;
    private String series;
    private List<String> beneficios;
    private List<String> precauciones;
    private List<String> erroresComunes;
    private List<String> recomendaciones;

    public Ejercicio(String nombre, List<String> musculos, List<String> equipo, String series, List<String> beneficios, List<String> precauciones, List<String> erroresComunes, List<String> recomendaciones) {
        this.nombre = nombre;
        this.musculos = musculos;
        this.equipo = equipo;
        this.series = series;
        this.beneficios = beneficios;
        this.precauciones = precauciones;
        this.erroresComunes = erroresComunes;
        this.recomendaciones = recomendaciones;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public List<String> getMusculos() {
        return musculos;
    }

    public void setMusculos(List<String> musculos) {
        this.musculos = musculos;
    }

    public List<String> getEquipo() {
        return equipo;
    }

    public void setEquipo(List<String> equipo) {
        this.equipo = equipo;
    }

    public String getSeries() {
        return series;
    }

    public void setSeries(String series) {
        this.series = series;
    }

    public List<String> getBeneficios() {
        return beneficios;
    }

    public void setBeneficios(List<String> beneficios) {
        this.beneficios = beneficios;
    }

    public List<String> getPrecauciones() {
        return precauciones;
    }

    public void setPrecauciones(List<String> precauciones) {
        this.precauciones = precauciones;

    public List<String> getErroresComunes() {

   Errores comunes: Inclinar el torso hacia adelante, Rodilla que pasa la
   punta del pie
   Recomendaciones: Dar un paso amplio, Mantener el torso recto

6) press militar
   Músculos: deltoides, tríceps, trapecio
   Equipo: barra, mancuernas
   Series: 3-4 series x 8-12 repeticiones
   Beneficios: Fuerza de hombros, Estabilidad del core
   Precauciones: Lesión de hombro, Cervicalgia
   Errores comunes: Arquear la espalda, Subir la barra por delante de la cara
   Recomendaciones: Activar el core, No bloquear la respiración

7) curl de bíceps
   Músculos: bíceps, braquial
   Equipo: mancuernas, barra
   Series: 3 series x 10-15 repeticiones
   Beneficios: Hipertrofia de brazos, Fuerza de agarre
   Precauciones: Epicondilitis, Lesión de muñeca
   Errores comunes: Balancear el torso, Usar impulso
   Recomendaciones: Mantener los codos pegados al torso, Bajar de forma
   controlada

8) fondos en paralelas
   Músculos: tríceps, pectoral mayor, deltoides anterior
   Equipo: paralelas
   Series: 3 series x 8-12 repeticiones
   Beneficios: Fuerza de empuje, Hipertrofia de tríceps
   Precauciones: Lesión de hombro, Lesión de codo
   Errores comunes: Bajar demasiado, Adelantar los hombros
   Recomendaciones: Mantener los codos cerca del cuerpo, Bajar hasta 90 grados

9) plancha abdominal
   Músculos: core, recto abdominal, oblicuos
   Equipo: colchoneta
   Series: 3 series x 30-60 segundos
   Beneficios: Estabilidad del core, Prevención de dolor lumbar
   Precauciones: Dolor lumbar, Lesión de hombro
   Errores comunes: Elevar la cadera, Hundir la zona lumbar
   Recomendaciones: Alinear cabeza, cadera y talones, Respirar de forma
   constante

10) hip thrust
    Músculos: glúteos, isquiotibiales
    Equipo: barra, banco
    Series: 3-4 series x 10-15 repeticiones
    Beneficios: Fuerza de glúteos, Potencia de cadera
    Precauciones: Dolor lumbar, Lesión de cadera
    Errores comunes: Hiperextender la espalda, Empujar con los talones
    Recomendaciones: Mantener el mentón al pecho, Apretar los glúteos arriba

--------------------------------------------------------------------------------
ENDPOINT 3: GET /musculo
--------------------------------------------------------------------------------

URL:
    http://localhost:3000/musculo?musculo=VALOR

Parámetro obligatorio (query string):
    musculo = nombre del músculo que se quiere buscar.

Qué hace:
    Recorre la lista de ejercicios y devuelve solamente aquellos cuya lista
    de "musculos" contiene exactamente el valor recibido.

    La comparación se hace con List.contains(), por lo tanto:
        - Distingue mayúsculas y minúsculas.
        - Distingue acentos.
        - No hace búsquedas parciales.
        - El valor debe ser idéntico a uno de los elementos de la lista.

Respuesta:
    Código HTTP: 200 OK
    Content-Type: application/json
    Cuerpo: arreglo JSON (puede tener 0, 1 o varios ejercicios).

Ejemplos reales probados:

    GET http://localhost:3000/musculo?musculo=gl%C3%BAteos
    (equivale a: musculo=glúteos)

    Devuelve 4 ejercicios:
        - sentadilla
        - peso muerto
        - zancadas
        - hip thrust

    GET http://localhost:3000/musculo?musculo=tr%C3%ADceps
    (equivale a: musculo=tríceps)

    Devuelve 3 ejercicios:
        - press de banca
        - press militar
        - fondos en paralelas

    GET http://localhost:3000/musculo?musculo=piernas

    Devuelve un arreglo vacío: []
    (porque "piernas" no es un valor exacto de la lista; los valores son los
    nombres de los músculos, no los grupos como "piernas").

Si se omite el parámetro:

    GET http://localhost:3000/musculo

    Código HTTP: 400 Bad Request
    Content-Type: application/json
    Cuerpo:
    {"timestamp":"...","status":400,"error":"Bad Request","path":"/musculo"}

    Esto lo hace Spring automáticamente porque @RequestParam es obligatorio.

Si el valor no coincide con nada:

    Código HTTP: 200 OK
    Cuerpo: []

9. COMPORTAMIENTO DEL FILTRO POR MÚSCULO
================================================================================

El filtro está implementado así en el controlador:

    @GetMapping("/musculo")
    public List<Ejercicio> musculo(@RequestParam String musculo){
        List<Ejercicio> ejerciciosConMusculo = new ArrayList<>();
        for(Ejercicio ejercicio:ejercicios){
            if(ejercicio.getMusculos().contains(musculo)){
                ejerciciosConMusculo.add(ejercicio);
            }
        }
        return ejerciciosConMusculo;
    }

Es el mismo patrón del video (allí se filtraba por síntoma y se usaba
contains sobre las indicaciones).

VALORES VÁLIDOS PARA EL PARÁMETRO "musculo"
(tal como están escritos en el código, en minúscula y con acentos):

    cuádriceps
    glúteos
    isquiotibiales
    pectoral mayor
    tríceps
    deltoides anterior
    espalda baja
    dorsal ancho
    bíceps
    romboides
    deltoides
    trapecio
    braquial
    core
    recto abdominal
    oblicuos

CÓDIGOS URL DE LOS ACENTOS

Si escribes la URL a mano, los acentos deben ir codificados. El navegador y
Postman lo hacen automáticamente; en la barra del navegador puedes escribir
la palabra con acento y el navegador la codifica.

    á  ->  %C3%A1
    é  ->  %C3%A9
    í  ->  %C3%AD
    ó  ->  %C3%B3
    ú  ->  %C3%BA

Ejemplos:

    glúteos  ->  gl%C3%BAteos
    tríceps  ->  tr%C3%ADceps
    bíceps   ->  b%C3%ADceps
    cuádriceps -> cu%C3%A1driceps

EJEMPLO DE LO QUE DEVUELVE CADA VALOR (referencia)

    glúteos           -> sentadilla, peso muerto, zancadas, hip thrust
    cuádriceps        -> sentadilla, zancadas
    isquiotibiales    -> sentadilla, peso muerto, zancadas, hip thrust
    pectoral mayor    -> press de banca, fondos en paralelas
    tríceps           -> press de banca, press militar, fondos en paralelas
    deltoides anterior-> press de banca, fondos en paralelas
    deltoides         -> press militar
    bíceps            -> dominadas, curl de bíceps
    dorsal ancho      -> dominadas
    romboides         -> dominadas
    trapecio          -> press militar
    braquial          -> curl de bíceps
    core              -> plancha abdominal
    recto abdominal   -> plancha abdominal
    oblicuos          -> plancha abdominal
    espalda baja      -> peso muerto

NOTA:
    Como la comparación es exacta, "Glúteos" con mayúscula devuelve [] y
    "gluteos" sin acento también devuelve []. Usa los valores de la lista.

14. SOLUCIÓN DE PROBLEMAS FRECUENTES
================================================================================

PROBLEMA: "Port 3000 was already in use" / el puerto está ocupado.
-------------------------------------------------------------------------------
Significa que ya hay otra aplicación usando el puerto 3000 (puede ser una
ejecución anterior que quedó abierta).

Solución:
    1. Detener la ejecución anterior en IntelliJ (botón rojo) o cerrar la
       terminal donde estaba corriendo.
    2. O cambiar el puerto en application.properties:

           server.port=8080

    3. En Windows se puede ver qué proceso usa el puerto con:

           netstat -ano | findstr :3000

PROBLEMA: No responde http://localhost:3000
-------------------------------------------------------------------------------
Revisar:
    - Que la aplicación siga corriendo (la terminal o IntelliJ deben seguir
      abiertos; si se cierra, el servidor se apaga).
    - Que en la consola aparezca "Tomcat started on port 3000".
    - Que la URL esté bien escrita.
    - Que no haya otro programa usando el puerto.

PROBLEMA: El filtro devuelve [] (arreglo vacío)
-------------------------------------------------------------------------------
El valor no coincide exactamente. Revisar:
    - Mayúsculas y minúsculas: debe ser "glúteos", no "Glúteos".
    - Acentos: "glúteos" lleva tilde; "gluteos" no coincide.
    - Que sea un músculo de la lista de la sección 9.
    - Que no se esté buscando un grupo como "piernas", porque ese valor no
      existe en los datos.

PROBLEMA: "MissingServletRequestParameterException" o error 400 en /musculo
-------------------------------------------------------------------------------
Falta el parámetro. La URL debe incluir ?musculo=VALOR. Ejemplo:

    http://localhost:3000/musculo?musculo=bíceps

PROBLEMA: "java no se reconoce como nombre de un comando"
-------------------------------------------------------------------------------
Java no está en el PATH. Usar IntelliJ o definir JAVA_HOME (ver sección 11).

PROBLEMA: Los cambios no se reflejan
-------------------------------------------------------------------------------
Detener la aplicación y volver a ejecutarla. El proyecto no usa devtools, así
que no recarga automáticamente.

PROBLEMA: Caracteres raros en la consola (Ã¡, Ã³)
-------------------------------------------------------------------------------
Es solo la forma en que algunas consolas de Windows muestran el texto. El JSON
real se devuelve en UTF-8 y el navegador/Postman lo muestran correctamente.
Se verificó que la respuesta contiene "cuádriceps" y "glúteos" bien escritos.
